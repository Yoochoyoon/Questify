## 🎯 1. 기획 배경 및 해결 과제
### **현재 상황 및 문제점:**  
  
**"공부 해야지! ...그전에 유튜브좀 볼까?" ...정신을 차려보니 어느샌가 잘시간..?**  
*허무함++; 자괴감++; 내일할일++;*  
이처럼 계획과 시간관리가 없으면 하루가 짧고 무의미하게 느껴진다.  
그럼 시간표를 만든다면 되지 않을까?  
그럴리가...  이미 미루는 것이 습관이 되버렸다면 시간표를 지키는 것도 오래 못간다.  

### **우리가 제공할 해결책:** (그 불편함을 우리 웹사이트가 어떻게 해결해 줄 것인지 적어주세요)  
  
* **우리는 왜 시간표를 만들어 봤자 안지킬까?**  
이유는 하루종일 억지로 시간표를 지켜봤자 **당장 얻는 도파민**이 없기 때문이다.  
*( 오늘 하루 보람찼다 <<< 아 하기싫어 )*  

* **공부는 미루면서 왜 게임은 하고싶을까?**  
RPG 게임에서는 퀘스트, 사냥, 보스전을 수행하면 자신의 성장이 바로 수치로 보이기 때문에 보상체계가 확실하다.  
경쟁게임 즉, 롤, 오버워치와 같은 게임만 하더라도 매판이 끝날때마다 자신의 점수가 변동하는 것이 실시간으로 보이기 때문에  
계속 하게 되는 동기부여가 된다.  
RPG 게임에서는 퀘스트를 수행하면 자신의 성장이 바로 수치로 보이기 때문에 보상체계가 확실하다. 또한 자신만의 캐릭터와 공간을 꾸며 나가며 환경 나아지는게 보이기 때문에 계속 하게되는 동기부여가 된다.

* **그렇다면 시간표 수행률에 따라 캐릭터를 성장시키는 게임이 있다면 어떨까?**  
대부분의 온라인 게임에는 일일퀘스트라는 시스템이 있다.   
일일퀘스트는 그 말대로 매일 할수 있기 때문에, 유저들은 자신의 캐릭터를 빠르게  
강화 시키기 위해 이를 빠짐없이 수행한다. 하루라도 빠지면 손해라고 생각하기 때문이다.  
우리는 자신이 수행해야 할 업무를 이 일일퀘스트와 대응시켜서 시간표를 수행하면 일일퀘스트를 수행한것 같이 자신의 분신과 같은 캐릭터가 직관적으로 성장하는 것을 보여주는  
**게임과 같은 스케줄러** 를 만들 계획이다.

## ⭐ 3. 핵심 기능
> 프론트엔드 환경에서 3주 내에 구현할 수 있는 핵심적인 기능 딱 3가지를 정의합니다.
1. 퀘스트 시스템1
  퀘스트를 추가하고 클리어 하는 기능
  클리어 시 경험치를 얻어 레벨업이 가능한 기능.(투두리스트개념)  
  퀘스트 추가 → 클리어 버튼 → 클리어 → 경험치와 코인 얻기(얻는 걸  보상을 적게 설정)

2. 퀘스트 시스템2
    코인걸기 →퀘스트이름+설명을 설정→ 시간을 설정 → 실행 → 타이머 작동 → 타이머가 완료 →문제를 만듬→  클리어→건 코인의 2배정도 얻기

    만약 클리어를 못한다면? 코인 반토막
    퀘스트중 다른 창이나 다른 걸 하면 중지 되도록(ex 명지전문대 시험 시스템)

  
    2번 퀘스트에 넣은 문제 표시 → 정답 입력 → 정답시 클리어
    문제 만들기 폼을 따로 작성해서 다음날 다시 풀 수 있도록 만들기.

3. 꾸미기 시스템
  캐릭터와 캐릭터가 머무는 방을 꾸밀 수 있도록 만들기  
  상점 시스템 꾸밀 수 있는 아이템 판매 (코인으로 구매 가능) 경험치에 따라 구매 가능한 아이템의 갯수 증가
